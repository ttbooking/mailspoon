# 05. Журнал пересылок и дедупликация

> ✅ **Реализовано в 2.0.0.** Таблица `relayed_messages` (статусы
> `pending`/`delivered`/`failed`, дедуп по `Message-Id`) — ядро store-and-forward.
> Retention-очистка реализована после 2.0.1 через Eloquent `Prunable`: запись
> удаляется только вместе со связанным MIME-архивом из #19.

**Приоритет:** 🟡 средний · **Трудоёмкость:** M

## Проблема

Нет следов того, что и когда было переслано. При сбое или повторном запуске
`imap:pull` (а с ретраями из #01 — тем более) одно письмо может уйти на эндпоинт
несколько раз. Также невозможно ответить на вопросы «дошло ли письмо X»,
«сколько писем переслали за сутки», «какой был статус ответа».

`DB_CONNECTION` сейчас `null` — БД не используется вовсе.

## Цель

Персистентный журнал каждой попытки доставки и защита от повторной отправки
одного и того же письма (по `Message-Id`).

## Предлагаемое решение

Таблица `relayed_messages` (миграция):

| Поле | Назначение |
| ---- | ---------- |
| `message_id` | `Message-Id` письма (уникальный индекс) |
| `mailbox` / `folder` | источник |
| `endpoint` | куда слали |
| `status` | `pending` / `delivered` / `failed` |
| `response_code` | HTTP-код последнего ответа |
| `attempts` | число попыток |
| `delivered_at` | время успешной доставки |

Дедуп в начале listener:

```php
if (RelayedMessage::where('message_id', $message->messageId())->delivered()->exists()) {
    $message->markSeen();
    return;
}
```

После доставки — запись/обновление статуса. Хорошо ложится на очередь из #01
(статусы `pending → delivered/failed`).

Команда обслуживания: штатная `php artisan model:prune
--model=App\\Models\\RelayedMessage`. Автоматический запуск включается через
`SPOON_RETENTION_DAYS`; очистка журнала и архива выполняется совместно.

## Изменения конфигурации

```dotenv
DB_CONNECTION=sqlite          # достаточно файла БД для лёгкого деплоя
SPOON_DEDUP=true
SPOON_RETENTION_DAYS=30
```

## Замечания

- SQLite-файла достаточно — не тянет тяжёлую инфраструктуру.
- `Message-Id` может отсутствовать; фолбэк — хеш от `body-mime`.
- Связано с #01 (ретраи) и #07 (метрики берутся из этой таблицы).

## Definition of Done

- [ ] Миграция + модель `RelayedMessage`.
- [ ] Повторная доставка одного `Message-Id` не происходит.
- [ ] Каждая попытка фиксируется со статусом и кодом ответа.
- [x] Очистка старых завершённых записей вместе со связанным MIME-архивом.
