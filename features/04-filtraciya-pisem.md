## Проблема

Сейчас пересылается **каждое** непрочитанное письмо. Нет способа отсеять спам,
авто-ответы, рассылки или, наоборот, переслать только письма от определённых
отправителей/с определённой темой. На стороне получателя приходится фильтровать
постфактум, а трафик/нагрузка идут впустую.

## Цель

Декларативные правила include/exclude, применяемые до отправки вебхука.

## Предлагаемое решение

Правила в `config/spoon.php` (глобально или на маршрут из #03):

```php
'filters' => [
    'allow' => [
        'from'    => ['*@trusted.com', 'boss@example.com'],
        'subject' => ['/invoice/i'],          // регэксп или glob
    ],
    'deny' => [
        'from'    => ['no-reply@*', 'mailer-daemon@*'],
        'header'  => ['Auto-Submitted' => 'auto-replied'],
        'has_attachment' => false,            // напр. пропускать только с вложением
    ],
],
```

Небольшой класс `MessageMatcher`, вызываемый в начале listener:

```php
if (! $this->matcher->passes($event->message)) {
    $event->message->markSeen();   // или оставить unseen — настраиваемо
    return;
}
```

Логика: `deny` имеет приоритет над `allow`; пустой `allow` = разрешить всё.

## Изменения конфигурации

Управление тем, что делать с отфильтрованным письмом:

```dotenv
SPOON_FILTERED_ACTION=mark_seen   # mark_seen | leave | move:Filtered
```

(`move:` пересекается с #06 — действия после обработки.)

## Замечания

- Сопоставление по заголовкам требует, чтобы части были загружены (`--with`).
- Регэкспы валидировать на старте, чтобы кривое правило не валило воркер.
- Логировать причину отсева (см. #05/#07) для отладки.
