## Сводный взгляд

Сейчас вся логика приложения — это три команды (`imap:pull`, `imap:sentry`,
`imap:watch`) и один listener `App\Listeners\NotifyNewMessage`, который шлёт
POST и сразу зовёт `markSeen()`. Это надёжно работает для happy-path, но:

- нет гарантий доставки (письмо «теряется» при сбое эндпоинта — см. #01);
- payload минимален (только `body-mime`, см. #02);
- нет наблюдаемости и тестов (см. #07, #08).

Рекомендуемый минимальный набор для production-готовности: **#01 + #02 + #08**
(а для ящиков Gmail/Microsoft 365 — обязательно ещё **#11**, иначе подключиться
по паролю не выйдет).
