# Mailspoon — наработки по фичам

Каталог с проработками возможных функций Mailspoon. Каждый файл — отдельная
фича: проблема, предлагаемое решение, эскиз реализации с привязкой к текущему
коду, изменения конфигурации и грубая оценка трудоёмкости.

Это рабочие заметки (черновики дизайна), а не обязательства. Порядок номеров —
примерный приоритет: чем меньше номер, тем выше отдача.

## Сводный взгляд

**Сделано в 2.0.0** — архитектура store-and-forward: приём (`imap:*`) сохраняет
письмо в хранилище и фиксирует в `relayed_messages`, доставку отдельно выполняет
`spoon:deliver` по планировщику.

- **#05** (журнал + дедуп) и **#19** (архив) — ядро store-and-forward.
- **#01** (надёжная доставка) — влита в `spoon:deliver` (двухуровневый ретрай).
- **#16** (планировщик) — `withoutOverlapping`, режим cron-poll.
- **#08** (тесты) — частично: есть Pest-покрытие захвата/доставки/ретрая/
  планировщика; CI-workflow ещё нет.

**Ближайшие кандидаты дальше:** #02 (полный payload), #11 (OAuth2 для
Gmail/M365 — иначе к ним не подключиться), #08 (добить CI), а также небольшие
хвосты: команды очистки `spoon:prune`/`spoon:archive:prune` из #05/#19.
