# 20. Graceful shutdown и обработка сигналов

**Приоритет:** 🟡 средний · **Трудоёмкость:** S–M

## Проблема

`imap:sentry`/`imap:watch` — долгоживущий процесс. При деплое/рестарте
оркестратор шлёт `SIGTERM`, а затем `SIGKILL`. Если воркера убьют в момент между
успешным POST и `markSeen()` — письмо пересоздастся как непрочитанное и уйдёт
**повторно** (дубликат у получателя). Если в момент обработки — текущее письмо
может «зависнуть» в неопределённом состоянии. Нет управляемого завершения и
понимания, безопасно ли сейчас перезапускать.

## Цель

Корректное завершение по сигналу: дообработать текущее письмо (или атомарно
откатиться), закрыть IMAP-соединение, выйти с нулевым кодом — без дублей и
потерь.

## Предлагаемое решение

1. Перехватывать `SIGTERM`/`SIGINT` (нужен `ext-pcntl`, см. #09) и выставлять
   флаг «останавливаемся»: не начинать новое письмо, дать завершиться текущему,
   затем выйти:

   ```php
   pcntl_async_signals(true);
   $stopping = false;
   pcntl_signal(SIGTERM, function () use (&$stopping) { $stopping = true; });
   // в цикле watch: if ($stopping) { $mailbox->disconnect(); return self::SUCCESS; }
   ```

2. Сделать единицу работы атомарной по отношению к рестарту: помечать
   прочитанным только после подтверждённой доставки (#01), а защиту от дублей
   обеспечить дедупом по `Message-Id` (#05). Тогда повтор после внезапного
   `SIGKILL` будет отброшен получателем/журналом.

3. Уважать `stopwaitsecs` (supervisor) / `TimeoutStopSec` (systemd) — выходить
   заметно раньше, чтобы не доводить до `SIGKILL`.

## Изменения конфигурации

```dotenv
SPOON_SHUTDOWN_GRACE=25     # сек на завершение текущей работы до выхода
```

## Замечания

- Полностью «exactly-once» в IMAP недостижимо — цель «at-least-once + дедуп»
  (поэтому критична связка с #01 и #05).
- Требует `pcntl`; в Docker-образе (#09) расширение должно быть установлено.
- `--timeout` IDLE стоит держать меньше grace-периода оркестратора.

## Definition of Done

- [ ] `SIGTERM` завершает воркер штатно с кодом 0.
- [ ] Текущее письмо не бросается в неопределённом состоянии.
- [ ] Связка с #01/#05 исключает дубликаты при аварийном убийстве.
- [ ] IMAP-соединение корректно закрывается при выходе.
