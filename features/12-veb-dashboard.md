# 12. Веб-дашборд

**Приоритет:** 🟢 низкий (ждём реального запроса) · **Трудоёмкость:** L

> Актуализация (3.0, пакет): эскиз писался для standalone-приложения. В
> пакетной модели это либо UI в стиле Horizon/Telescope — пакет публикует
> маршруты и фронт (L+, тащит зависимости во все инсталляции), либо хост сам
> строит экран поверх модели `RelayedMessage`, которая уже доступна в его
> приложении как обычный Eloquent. Replay закрывается CLI
> ([#15](15-replay-i-dry-run.md)). Понижено до «ждём реального запроса».

## Проблема

У приложения нет ни одного веб-маршрута (`routes/` отсутствует) — это чистый
CLI-воркер. Чтобы посмотреть, что пересылается, увидеть провалы, повторить
доставку или проверить статус ящиков, приходится лезть в логи/БД руками.
Оператору без доступа к серверу наблюдать за реле невозможно.

## Цель

Простая защищённая веб-панель: статус воркеров, журнал пересылок, повтор
проваленных, базовые метрики.

## Предлагаемое решение

Опирается на журнал из #05 и heartbeat из #07. Минимальный набор экранов:

- **Дашборд** — статусы ящиков (свежесть heartbeat), счётчики
  delivered/failed/pending за период.
- **Журнал** — таблица `relayed_messages` с фильтрами (ящик, статус, дата),
  просмотр деталей письма и последнего ответа эндпоинта.
- **Действия** — кнопка «переотправить» для проваленных (использует #15
  replay), отметка обработанным.

Технически: пакет маршрутов с префиксом, защита `auth`/Basic-Auth/Sanctum,
Blade + лёгкий фронт (или Livewire). Маршруты выключены по умолчанию.

```php
// routes/web.php (новый)
Route::middleware(config('spoon.dashboard.middleware'))
    ->prefix('mailspoon')
    ->group(base_path('routes/dashboard.php'));
```

## Изменения конфигурации

```dotenv
SPOON_DASHBOARD=true
SPOON_DASHBOARD_PATH=mailspoon
```

```php
'dashboard' => [
    'enabled' => env('SPOON_DASHBOARD', false),
    'middleware' => ['web', 'auth'],   // или basic-auth
],
```

## Замечания

- Зависит от #05 (данные журнала) и #07 (heartbeat/метрики); без них дашборду
  нечего показывать.
- Доступ к содержимому писем — чувствительные данные, обязательна авторизация.
- Альтернатива «по-дешёвле»: только read-only страница из CLI-команды
  `spoon:stats`, если полноценный UI избыточен.

## Definition of Done

- [ ] Защищённые маршруты дашборда, выключены по умолчанию.
- [ ] Просмотр журнала с фильтрами.

- [ ] Сводные метрики на главной.
