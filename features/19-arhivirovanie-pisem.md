# 19. Архивирование сырых писем

**Приоритет:** 🟢 низкий · **Трудоёмкость:** M

## Проблема

После пересылки и `markSeen()` единственная копия письма остаётся в IMAP-ящике —
до тех пор, пока его кто-нибудь не удалит/папка не очистится. Нет независимого
архива сырого MIME: невозможно расследовать инцидент, переотправить после
ротации почты, выполнить юридический/комплаенс-хранение или переиндексировать
историю, если ящик уже почистили.

## Цель

Складывать сырой MIME каждого обработанного письма в настраиваемое хранилище
(локальный диск, S3) с предсказуемым именованием и сроком хранения.

## Предлагаемое решение

Использовать Laravel Filesystem (`config/filesystems.php` уже есть). После
успешной доставки (или до неё — настраиваемо) сохранять `.eml`:

```php
Storage::disk(config('spoon.archive.disk'))->put(
    sprintf('%s/%s/%s.eml', $mailbox, now()->format('Y/m/d'), $messageId),
    (string) $event->message,
);
```

Связать путь с журналом (#05), чтобы из записи можно было открыть исходник и
переотправить (#15). Команда очистки по сроку хранения:

```bash
php artisan spoon:archive:prune --days=90
```

## Изменения конфигурации

```php
'archive' => [
    'enabled'   => env('SPOON_ARCHIVE', false),
    'disk'      => env('SPOON_ARCHIVE_DISK', 'local'),
    'retention' => env('SPOON_ARCHIVE_DAYS', 90),
    'when'      => env('SPOON_ARCHIVE_WHEN', 'delivered'), // always | delivered
],
```

```dotenv
SPOON_ARCHIVE=true
SPOON_ARCHIVE_DISK=s3
SPOON_ARCHIVE_DAYS=90
```

## Замечания

- Сырой MIME = персональные данные → учесть шифрование на диске и срок
  хранения (комплаенс).
- `when=always` сохраняет даже недоставленные — полезно для расследований.
- Архив — источник для replay (#15) и для повторной индексации.

## Definition of Done

- [ ] Сохранение `.eml` на выбранный диск с осмысленным путём.
- [ ] Привязка к журналу (#05) для replay.
- [ ] Команда очистки по сроку хранения.
- [ ] Выключено по умолчанию.
